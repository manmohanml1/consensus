# CQ-105: Mobile-first photo-led discovery deck

**Milestone:** 0.2.1  
**Type:** feature  
**Depends on:** CQ-103, CQ-104
**GitHub:** [#7](https://github.com/manmohanml1/consensus/issues/7)

Present candidates through a phone-first, image-led card with optional horizontal swipe shortcuts and complete labeled button controls. Add responsive tablet/desktop adaptations without changing the decision semantics.

Generated sample media must be locally owned, explicitly illustrative, and prohibited from implying real venue facts. Real provider photos remain out of scope.

**Done when:** the four fixture candidates have labeled media, avoid/accept/prefer remain keyboard and screen-reader operable, swipe behavior is tested, mobile has no horizontal overflow, reduced motion keeps every capability, and product/ADR/place-data records agree.
