# Accessibility contract

- WCAG 2.2 AA is the release target.
- Every swipe action has a visible, labeled button and keyboard equivalent.
- Cards use ordered content and do not require drag precision.
- Focus never moves unexpectedly when a card exits.
- Status changes use a polite live region; the final result receives deliberate focus.
- Color is never the only indicator of vote meaning or data confidence.
- Reduced motion disables card rotation, parallax, confetti, and nonessential transitions.
- Touch targets are at least 44 by 44 CSS pixels.
- Text supports 200% zoom without horizontal scrolling at 320 CSS pixels.
- Haptics and sound are optional enhancements and never convey unique information.
- The room works with screen readers in roster, constraint, voting, recovery, and result states.
