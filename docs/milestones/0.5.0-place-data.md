# Milestone 0.5.0: Trustworthy place data

## Outcome

The product creates an actionable nearby food list without unsupported claims.

## Work

- compare and provision a licensed place provider;
- normalization with provenance/freshness and attribution;
- constraint filtering for hours, price, diet, accessibility and distance;
- bounded cache, circuit breaker and data-quality metrics;
- host correction/removal and honest unavailable states;
- map handoff validation across supported devices.

## Exit gate

Coverage and freshness meet the selected launch geography target; missing fields remain visibly missing; licensing and caching review is recorded; provider outage never invents data.
