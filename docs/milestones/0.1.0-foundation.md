# Milestone 0.1.0: Foundation and single-device slice

## Outcome

A contributor can understand, run, test, and extend Consensus without relying on the original blueprint or chat history.

## Scope

- repository governance, product, architecture, security, privacy, and delivery records;
- Next.js application shell and accessible sample room;
- pure decision-engine package and invariant tests;
- CI, CodeQL, Dependabot, issue intake, and release provenance;
- no external providers, accounts, persistence, or multiplayer claims.

## Exit gate

- `pnpm verify` passes from a clean locked install;
- sample flow works with buttons, keyboard, mobile viewport, and reduced motion;
- hard constraints exclude candidates before scoring;
- docs and implementation use the same ruleset terminology;
- issue-ready plans exist for 0.2–0.6.
