# Milestone 0.2.0: Host-led decision MVP

## Outcome

A host completes a realistic food decision on one device using sample or manually entered candidates.

## Work

- room setup, target time, constraints, candidate review, ballot and result states;
- manual candidate validation and stable sample decks;
- undo, no-safe-result, runner-up and explanation UX;
- map/share link validation;
- Playwright keyboard/mobile/reduced-motion journeys;
- 10 moderated usability sessions.

## Exit gate

At least 8/10 testers complete the flow without instruction; constraint conflicts and outcome reasons are understood; no screen requires swipe gestures.

## Implementation status

The technical slice is implemented on `codex/decision-mvp`:

- validated room intent, target time, 2–8-person locked roster, and group-safe constraint summaries;
- stable illustrative candidates plus bounded manual entry with explicit unknown evidence and HTTP(S)-only links;
- deterministic prefer/accept/avoid ballots, a single strongest pick, undo, runner-up, no-safe-result, and commitment handoff;
- desktop, 390×844 mobile, keyboard, and reduced-motion Playwright journeys;
- Vercel-ready repository build configuration and immutable CI diagnostics.

The milestone remains active until 10 moderated usability sessions satisfy the 8/10 exit gate. Completing code does not authorize production deployment or a release.
