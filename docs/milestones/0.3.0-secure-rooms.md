# Milestone 0.3.0: Secure ephemeral rooms

## Outcome

Multiple anonymous participants can join a durable temporary room with correct authorization and lifecycle semantics.

## Work

- resolve ADR 0007 and provision the approved transactional store;
- schema, forward migrations, room capabilities, hashed tokens and expiry;
- locked roster, host recovery, indistinguishable unauthorized responses;
- idempotent command API and authorized projections;
- concurrency, authorization, migration, retention and deletion tests;
- threat-model review.

## Current status

Active. CQ-205 established the versioned provider-neutral room protocol. CQ-202 completed the portable room schema, role separation, checksum-protected forward migrations, and disposable PostgreSQL evidence; the first owner-authorized shared non-production Neon migration applied migrations 0001–0005 at commit `2fc5d20` on 2026-09-02. CQ-203 completed server-only capability issuance, keyed fingerprints, authorization, redaction, and cookie delivery. CQ-204/CQ-210 completed transactional command handlers with capability-authorized, privacy-minimized projections. CQ-206/CQ-213 completed the host creation boundary, random non-authoritative invitation locators, and anonymous abuse circuit breakers. CQ-207/CQ-211 completed pending admission, explicit host approval/removal, participant departure, immutable locked electorates, and concurrency evidence for duplicate lock/vote/resolve and expiry races. CQ-208 delivered authenticated terminal expiry and bounded aggregate deletion. CQ-209 completed host-authorized, short-lived browser transfer with atomic capability rotation. A distinct least-privilege runtime login and protected Preview room-creation smoke are verified, with the synthetic aggregate removed afterward. CQ-198 and CQ-201 are complete. CQ-212 remains open for separately authorized hosted restore/teardown evidence, and CQ-214 remains the dependent exit review.

## Exit gate

No client can modify another participant, duplicate commands are harmless, roster changes cannot silently alter a ballot, expired test rooms are deleted, and rollback/recovery is documented.
