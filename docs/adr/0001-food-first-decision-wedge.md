# ADR 0001: Food-first decision wedge

**Status:** Accepted

## Context

The reference idea spans food, movies, activities, and arbitrary polls. Each category has different inventory, constraints, data rights, and action handoffs. Broad scope would hide whether the core product changes real behavior.

## Decision

Prove nearby food decisions for groups of 2–8 before expanding categories. Optimize completed, accepted plans rather than swipes or session length.

## Consequences

The MVP can model dietary, accessibility, price, distance, hours, and map handoff deeply. Category expansion requires evidence from the MVP gate and a new domain/provider assessment.
